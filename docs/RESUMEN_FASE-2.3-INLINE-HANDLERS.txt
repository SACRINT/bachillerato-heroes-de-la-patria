================================================================================
  VULNERABILIDADES IDENTIFICADAS
================================================================================

🔴 CRÍTICAS: CSP Violations (Content Security Policy)
   • Afecta: 124 archivos
   • Severidad: CRÍTICA
   • Impacto: Navegador bloquea eventos si CSP no permite 'unsafe-inline'
   • Requer Refactorización: OBLIGATORIA

🟠 ALTOS: XSS via Parámetros en Onclick
   • Afecta: ~200+ manejadores con parámetros dinámicos
   • Severidad: ALTA
   • Impacto: Inyección de código a través de parámetros no escapados
   • Ejemplo: onclick="deleteItem('${id}')" - Si id contiene quote, XSS

🟡 MEDIOS: Event Handler Scope Pollution
   • Afecta: ~300+ manejadores
   • Severidad: MEDIA
   • Impacto: Acceso a variables globales desde atributos HTML
   • Solución: Encapsulación en funciones con parámetros explícitos

================================================================================
  PATRONES ENCONTRADOS
================================================================================

Patrón A: onclick Simple (Sin parámetros)
  • Cantidad: ~150 instancias
  • Complejidad: BAJA
  • Ejemplo: onclick="toggleMenu()"
  • Refactorización: 1:1 directa con addEventListener

Patrón B: onclick con Parámetros
  • Cantidad: ~400 instancias
  • Complejidad: MEDIA
  • Ejemplo: onclick="deleteItem(123)" o onclick="editUser('${id}')"
  • Refactorización: Usar atributos data-* + dataset API

Patrón C: onclick Múltiples Acciones
  • Cantidad: ~100 instancias
  • Complejidad: MEDIA-ALTA
  • Ejemplo: onclick="save(); closeModal(); refresh();"
  • Refactorización: Función wrapper para coordinar acciones

Patrón D: onclick Condicionales
  • Cantidad: ~50 instancias
  • Complejidad: ALTA
  • Ejemplo: onclick="if(x) doA(); else doB();"
  • Refactorización: Lógica en función JavaScript

Patrón E: onchange en Formularios
  • Cantidad: 28 instancias
  • Complejidad: MEDIA
  • Ejemplo: onchange="filterByDept(this.value)"
  • Refactorización: addEventListener('change') con value extraído
