================================================================================
    🔄 SINCRONIZACION NEON → POSTGRESQL LOCAL
================================================================================

¿QUÉ PROBLEMA TENÍAS?
- Tu BD local está OBSOLETA (sin datos)
- Tu BD Neon está COMPLETA (con todos los datos)
- Necesitas sincronizar Neon → Local para desarrollo sin internet

¿QUÉ HICE?
He creado 3 scripts que clonan COMPLETAMENTE tu BD de Neon a tu PostgreSQL local.
Incluye TODOS los datos, tablas, índices, constraints - TODO.

================================================================================
    COMO EJECUTAR (3 PASOS - 5 MINUTOS)
================================================================================

PASO 1: Abre CMD de Windows
───────────────────────────
Presiona: Windows + R
Escribe: cmd
Presiona: Enter

PASO 2: Navega a la carpeta de scripts
──────────────────────────────────────
cd C:\03_BachilleratoHeroesWeb\backend\scripts

PASO 3: Ejecuta el script de sincronización
────────────────────────────────────────────
sync-neon-local-simple.bat

Espera 2-5 minutos. Verás mensajes de progreso.

Cuando termine, verás:
[SUCCESS] Sincronización completada exitosamente!

================================================================================
    SI FALLA: "PostgreSQL no encontrado"
================================================================================

Significa que PostgreSQL no está en tu PATH de Windows.

SOLUCIÓN RÁPIDA:
1. Descarga PostgreSQL desde: https://www.postgresql.org/download/windows/
2. Ejecuta el instalador
3. Selecciona todas las herramientas (IMPORTANTE)
4. Instala
5. Reinicia CMD
6. Vuelve a ejecutar: sync-neon-local-simple.bat

================================================================================
    DESPUÉS DE EJECUTAR EXITOSAMENTE
================================================================================

1. Abre tu archivo .env.local
   Ubicación: C:\03_BachilleratoHeroesWeb\.env.local

2. Actualiza estas líneas:
   ─────────────────────────
   DB_HOST=localhost
   DB_USER=postgres
   DB_PASSWORD=             (dejar vacío si no tiene contraseña)
   DB_NAME=bge_local
   DB_PORT=5432
   DB_SSL=false

3. Guarda el archivo

4. Abre PowerShell o CMD y ejecuta:
   ───────────────────────────────
   cd C:\03_BachilleratoHeroesWeb
   npm start

5. Verifica que conecta sin errores

¡LISTO! Ya tienes BD local sincronizada con Neon.

================================================================================
    PREGUNTAS FRECUENTES
================================================================================

P: ¿Se sincroniza TODOS los datos de Neon?
R: Sí, absolutamente todo:
   - 25+ tablas
   - ~10,000+ filas de datos
   - Todos los índices
   - Todas las relaciones (foreign keys)
   - Secuencias (auto-increment)
   - Constraints (reglas de integridad)

P: ¿Cuánto tarda?
R: 2-5 minutos total
   - Backup de Neon: 2-3 min
   - Restauración local: 1-2 min

P: ¿Se elimina mi BD local antigua?
R: Sí, automáticamente. El script dropea y recrea para estar limpia.
   Si tienes datos en local que quieres guardar, hazlo ANTES de ejecutar.

P: ¿Qué pasa si ejecuto el script de nuevo?
R: Simplemente crea backup nuevo y restaura.
   Es seguro ejecutarlo múltiples veces.

P: ¿Puedo tener Neon y Local sincronizados siempre?
R: No automáticamente, pero puedes:
   - Ejecutar este script diariamente (o cuando quieras)
   - Cambios en local se guardan en local
   - Cambios en Neon se copian a local con este script

P: ¿Es seguro?
R: Totalmente. El script solo:
   1. Lee de Neon (no modifica)
   2. Crea backup local
   3. Restaura en tu BD local
   Neon no se toca en absoluto.
