🔍 CAUSA RAÍZ IDENTIFICADA:
───────────────────────────────────────────────────────────────────────────────
En archivo: partials/footer.html (líneas 186-188)

PROPIEDADES CSS PROBLEMÁTICAS:
┌─────────────────────────────────────────────────────────────────────┐
│  .footer-main {                                                      │
│      width: 100vw;           ❌ Causa: Ancho del VIEWPORT (100vw)  │
│      margin-left: 50%;       ❌ Causa: Margen negativo             │
│      transform: translateX(-50%);  ❌ Causa: Transform incorrecto   │
│  }                                                                   │
└─────────────────────────────────────────────────────────────────────┘

EFECTO: El footer se comporta como elemento FLOTANTE/OVERLAY en lugar de ser
        parte del flujo normal de la página

───────────────────────────────────────────────────────────────────────────────

✅ SOLUCIÓN IMPLEMENTADA:
───────────────────────────────────────────────────────────────────────────────
Cambio en partials/footer.html (líneas 181-189):

ANTES:                                  DESPUÉS:
┌──────────────────────────────────┐   ┌──────────────────────────────────┐
│ .footer-main {                    │   │ .footer-main {                    │
│   background: ...;                │   │   background: ...;                │
│   color: #E3F2FD;                │   │   color: #E3F2FD;                │
│   position: relative;             │   │   position: relative;             │
│   overflow: hidden;               │   │   overflow: hidden;               │
│   width: 100vw;      ❌          │   │   width: 100%;       ✅           │
│   margin-left: 50%;  ❌          │   │   margin: 0;         ✅           │
│   transform: translateX(-50%); ❌ │   │   padding: 2rem 0;   ✅           │
│ }                                 │   │ }                                 │
└──────────────────────────────────┘   └──────────────────────────────────┘

CAMBIOS CLAVE:
  1. width: 100vw → 100%
     Razón: Respeta ancho del CONTAINER, no del viewport

  2. margin-left: 50% → margin: 0
     Razón: Elimina offset incorrecto que causaba desalineación

  3. transform: translateX(-50%) → REMOVIDO
     Razón: Centrado innecesario que causa overlay effect

  4. padding: 2rem 0 → AGREGADO
     Razón: Proporciona espaciado vertical apropiado
